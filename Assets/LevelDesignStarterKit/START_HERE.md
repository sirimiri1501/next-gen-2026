# START HERE

1. Mở project bằng Unity `2022.3.62f2`.
2. Chờ Unity compile/import xong. Starter Kit sẽ tự tạo asset lần đầu.
3. Nếu cần tạo lại, chọn `Tools > Level Design Starter Kit > Build or Rebuild Complete Kit`.
4. Mở scene `Generated/Scenes/LD_StarterKit_Demo` và nhấn Play.

Hướng dẫn đầy đủ: `Documentation/README_VI.md`  
Đề bài fresher: `Documentation/DE_BAI_FRESHER.md`
